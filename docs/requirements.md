# 需求文档

## 项目概述
英语四级背单词助手 — 面向中职毕业生的四级备考工具，网页版单页应用，双击即可在浏览器中使用。

## 目标用户
- 中职毕业生，英语基础一般
- 正在备考大学英语四级（CET-4）
- 非技术人员，需要简单直观的操作

## 功能需求

### F1 单词学习
- 展示单词卡片：英文、音标、词性
- 点击卡片翻转查看中文释义和例句
- "认识了"按钮标记已学，计入每日目标进度
- "加入生词本"收藏难点词

### F2 每日目标
- 默认每天学 20 个新词
- 顶部进度条显示当日完成量
- 可在设置中调整目标数量

### F3 单词复习（选择题）
- 从已学单词中随机出题
- 4 个中文选项（1 正确 + 3 干扰项）
- 答对显示绿色反馈，答错显示红色并展示正确答案
- 本轮统计正确率

### F4 生词本
- 内置词库收藏的单词列表
- 支持手动输入英文 + 中文释义添加生词
- 支持删除生词
- 数据持久化到浏览器

### F5 语法学习
- 四级核心语法知识分类展示
- 包含时态、语态、从句、虚拟语气等
- 每条语法配简要说明和例句

### F6 设置
- 调整每日目标数量
- 数据备份：导出 JSON 文件
- 数据恢复：导入 JSON 文件
- 重置学习进度

## 非功能需求
- NFR1：浏览器本地存储，不依赖网络
- NFR2：页面加载快（<2 秒），无外部资源请求
- NFR3：数据刷新不丢失（localStorage）
- NFR4：操作反馈清晰，按钮最小高度 44px（好点击）
