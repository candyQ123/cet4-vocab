# 设计规范

## 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#F0F6FC` | 淡蓝底色 |
| 卡片/内容区背景 | `#FFFFFF` | 白色 |
| 主强调色 | `#1976D2` | 按钮、进度条、选中态 |
| 浅强调色 | `#BBDEFB` | 标签、hover 背景 |
| 导航背景 | `#1565C0` | 深蓝，与白色文字对比 |
| 正确反馈 | `#4CAF50` | 答题正确绿色 |
| 错误反馈 | `#F44336` | 答题错误红色 |
| 文字主色 | `#212121` | 正文 |
| 文字辅助色 | `#757575` | 次要信息 |
| 分割线 | `#E0E0E0` | 轻量分隔 |

## 字体
- 系统默认字体（优先微软雅黑）
- 单词英文显示使用较大字号（28-32px）
- 中文释义使用常规字号（18-20px）
- 音标使用辅助色，稍小字号

## 组件规范

### 卡片
- 圆角：12px
- 阴影：`0 2px 8px rgba(0,0,0,0.08)`
- 内边距：20-24px
- 卡片间距：16px

### 按钮
- 圆角：8px
- 最小高度：44px
- 主按钮：蓝底白字 `#1976D2`
- 次要按钮：白底蓝边框
- Hover 态：颜色加深 10%

### 进度条
- 高度：8px
- 背景：`#E0E0E0`
- 填充：`#1976D2` 渐变到 `#42A5F5`
- 圆角：4px

### 导航栏
- 深蓝底 `#1565C0`
- 白色文字 + 下划线指示当前标签
- 固定于页面顶部

## 布局
- 最大宽度：600px（居中显示，适合学习场景）
- 导航固定顶部
- 内容区可滚动
- 卡片式布局，每屏聚焦一个内容块
