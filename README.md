# 四级背单词助手

面向中职毕业生的英语四级备考工具，帮助轻松背单词、学语法。

## 怎么用

双击 `src/index.html`，浏览器就会打开。不需要安装任何东西。

## 功能

- **学习**：单词卡片，点击翻转看释义，标记认识
- **复习**：选择题模式，看英文选中文，即时判断对错
- **生词本**：收藏难点词，也可以手动添加
- **语法**：四级核心语法知识，分类查看
- **每日目标**：默认每天 20 词，进度条跟踪
- **数据备份**：支持导出导入，不怕数据丢失

## 说明

- 数据保存在浏览器本地存储中，不会上传到任何地方
- 完全离线可用，不需要网络
- 推荐用 Chrome 或 Edge 浏览器打开
